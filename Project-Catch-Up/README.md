## Project Overview

The **Academic Course Finder** is a web-based platform that simplifies the search and management of academic data.  
It provides two main user roles:

- **Administrator:** Can manage professors, courses, and their relationships through CRUD operations.  
- **User:** Can browse and search for courses or professors without needing to log in.

---

## Current Focus

At this stage, the project focuses on:
- Designing the **system architecture**, considering two databases for better modularity and scalability.  
- Creating **GUI mockups** that define the visual identity and usability principles.  
- Preparing the **poster and paper drafts** that summarize the conceptual and experimental foundations.
